## 📘Lec 1

- **Terminologies:**
	- **Radix:** It's the base of the number system, e.g. decimal $\to$ base 10, binary $\to$ base 2 
	- **Digit Position:** Left of the dot positive, right of the dot negative 
	- **Digit Weight:** $Base^{Position}$ 
	- **Magnitude:** The sum of $Digit\ Value*Weight$ 
	- **Notes:**
		- $2^{10}\to$ K (kilo)
		- $2^{20}\to$ M (Mega)
		- $2^{30}\to$ G (Giga)
		- $2^{40}\to$ T (Tera)
- **Conversions:**
	- **Decimal to Any Base:**
		- **Integer:** Divide Base 
		- **Fraction:** Multiply 
	- **Any Base to Decimal:** 
		- **Integer Part:** Get the magnitude while the powers increase from $0 \to \infty$  
		- **Fraction Part:** Get the magnitude while the powers decrease from $-1 \to -\infty$ 
	- **Note:**
		- Every 4 bits is equivalent to one Hexadecimal digit 
		- Every 3 bits is equivalent to one Octal digit

## 📘Lec 2

- **Arithmetic Operations:**
	- **Addition:** If sum is more than the base, then we carry 1 to the next digits, and leave the reminder as the result of the current digit 
	- **Subtraction:** If first digit is smaller than the second digit, then we take base from the bigger digit, meaning decrease 1 from tens digits and increase base with the units digit 
- **Complements:**
	- **Diminished Radix Complement (r-1)’s Complement:**
		- **1's Complement:** 
			- All digits are toggled, and by adding the number to its 1's complement we get all the digits as ones
			- **Subtraction M-N is done By:**
				- Get 1’s Complement of N
				- Add M + N
				- If carry then Add carry to summation
				- If no carry then result = - 1’s complement of result
	- **Radix Complement r's complement:**
		- **2's Complement:**
			- Take 1’s complement then add 1, OR Toggle all bits to the left of the first ‘1’ from the right
			- **Subtraction M-N is done By:**
				- Get 2’s Complement of N
				- Add M + N
				- If carry then discard carry
				- If no carry then result = - 2’s complement of result
- **Rules:**
	- **Distributive:**
		- $x.(y+z)=(x.y)+(x.z)$ 
		- $x+(y.z)=(x+y).(x+z)$
	- **DeMorgan's Theorem:**
		- $(x+y)'=x'.y'$
		- $(x.y)'=x'+y'$
	- **Absorption:**
		- $x+(x.y)=x$
		- $x.(x+y)=x$ 
	- **Consensus Theorem:**
		- $xy+x'z+yz=xy+x'z$ 
		- $(x+y).(x'+z).(y+z)=(x+y).(x'+z)$ 
- **Precedence:**
	- Parentheses $\to$ NOT $\to$ AND $\to$ OR

## 📘Lec 3

- **Complement ($F'$):** Toggle all bits
- **Minterm:** It's an AND term containing every variable exactly once, either complemented or uncomplemented
- **Maxterm:** It's an OR term containing every variable exactly once, either complemented or uncomplemented
- **Sum of Product (SOP):** AND first then OR, e.g. $F=xy+x'z$ 
- **Product of Sum (POS):** OR first then AND, e.g. $F=(x+y)(x'+z)$ 
- **Canonical & Standard Forms:**
	- **Terminology:**
		- **Canonical:** Every term must contain all variables exactly once, either complemented or not,            e.g.   (SOP) $\to xyz+xy'z$,             (POS) $\to (x+y+z)(x+y'+z)$ 
		- **Standard:** The equation is arranged into SOP or POS, but terms don't have to contain all variables, e.g.  (SOP) $\to x+yz$,                    (POS) $\to x(y+z)$
	- **Conversions:**
		- **Standard $\to$ Canonical:**
			- **SOP:** $(X+X')$, e.g. $F=xy \to F=xy(z+z') \to F=xyz+xyz'$ 
			- **POS:** $XX'$, e.g. $F=x+y\to F=x+y+zz'\to F=(x+y+z)(x+y+z')$ 
		- **Canonical $\to$ Indices:**
			- **Minterm:** $x\to0$,  $x'\to 1$      Notation $\to$ $\sum ()$ 
			- **Maxterm:** $x\to 1$,  $x'\to 0$     Notation $\to$ $\prod()$

## 📘Lec 4

 - **K-Map Rules:**
	- Number of squares = $2^n$, where ($n$) = number of variables
	- Group only adjacent (1)'s (for SOP)
	- Group size must be ($2^k$): ($1, 2, 4, 8, 16, \ldots$)
	- Make groups as large as possible
	- Overlapping is allowed
- **Variable Position:**
	- **2 Variables:** $X\to$ row, $Y\to$ column
	- **3 Variables:** $X\to$ row, $Y\to$ two columns on the right, $Z\to$ two columns in the middle 
	- **4 Variables:** $W\to$ bottom two rows, $X\to$ middle two rows, $Y\to$ two columns on the right, $Z\to$ two columns in the middle 
- **Notes:**
	- The first and last rows/columns are adjacent
	- The four corners are adjacent and can form one group
- **Product of Sum (POS):**
	- Group the 0's instead of the 1's
	- Extract (F') in SOP form
	- Take the complement: (F=(F')')
	- Apply De Morgan's Law to obtain the final POS form
- **Don't-Care Conditions ($X$):**
	- Can be treated as either 0 or 1
	- Include X's only if they help create larger groups
	- X's do not have to be covered
	- Never create a group using only X's

## 📘Lec 5

- **NAND-Only Implementation:**
	- **NOT:** Connect both inputs together, ($x \text{ NAND } x = x'$)
	- **AND:** NAND followed by a NAND inverter, $((xy)')'=xy$
	- **OR:** Invert both inputs using NAND, then NAND them, $(x'y')'=x+y$
- **Notes:**
	- NAND-only implementation is best suited for **SOP expressions** 
- **NOR-Only Implementation:**
	- **NOT:** Connect both inputs together, $(x \text{ NOR } x = x')$ 
	- **OR:** NOR followed by a NOR inverter, $((x+y)')'=x+y$ 
	- **AND:** Invert both inputs using NOR, then NOR them, $(x'+y')'=xy$ 
- **Notes:**
	- NOR-only implementation is best suited for **POS expressions** 
- **XOR & XNOR:** 
	- **XOR ($\oplus$):**
		- $x\oplus y=xy'+x'y$ 
	- **XNOR ($\odot$):**
		- $x\odot y=xy+x'y'$ 
		- $x\odot y=(x\oplus y)'$ 
	- **Properties of XOR:** 
		- $x\oplus x=0$ 
		- $x\oplus x'=1$
		- $x\oplus 0=x$
		- $x\oplus 1=x'$
		- $x\oplus y=y\oplus x$ (Commutative)
		- $(x\oplus y)\oplus z=x\oplus(y\oplus z)$ (Associative)
		- $x\oplus y'=(x\oplus y)'=x'\oplus y$ 
	- **Notes:**
		- XOR of multiple variables = 1, when an **odd number of inputs are 1**
		- XNOR of multiple variables = 1, when an **even number of inputs are 1** 
- **Parity Generator & Checker:**
	- **Parity Bit:** An additional bit sent with data to detect transmission errors
	- **Even-Parity Generator:** Generates a parity bit that makes the total number of 1's even, $P=x\oplus y\oplus z$n
	- **Odd-Parity Generator:** Generates a parity bit that makes the total number of 1's odd, $P=(x\oplus y\oplus z)'$ 
	- **Even-Parity Checker:**
		- $C=x\oplus y\oplus z\oplus P$ 
		- $C=0\to$ No error detected
		- $C=1\to$ Parity error detected
	- **Odd-Parity Checker:**
		- $C=x\oplus y\oplus z\oplus P$
		- (C=1) → No error detected
		- (C=0) → Parity error detected
- **Combinational Logic Circuits:**
	- **Combinational Circuit:**
		- Consists of logic gates only (no memory or feedback)
		- Outputs depend ONLY on present inputs
		- For (n) inputs → (2^n) possible combinations
		- Can be represented using a Truth Table or Boolean Functions
	- **Notes:** 
		- Combinational $\to$ Depends on present inputs only
		- Sequential $\to$ Depends on present inputs AND previous state (memory)
- **Analysis:** 
	- **Overview:** Given a logic diagram, find its Boolean functions or Truth Table
	- **Methods:** 
		- **Boolean Functions:**
			- Label intermediate gate outputs $(T_1,T_2,\ldots)$
			- Write the Boolean expression for each gate
			- Substitute intermediate expressions until the final outputs depend only on the original inputs
		- **Truth Table:**
			- Count inputs $(n)\to$ Create ($2^n$) rows
			- Label intermediate gate outputs
			- Calculate each gate's output step by step
			- Continue until all final outputs are obtained
