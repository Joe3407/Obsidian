- **Interpret:** 
	- **Meaning:** Executing line by line, even if there is an error in a future line
	- **Example:** Translating a book from Arabic to English so we have a translator, and after each line I read he translates it, (JavaScript)
- **Compile:**
	- **Meaning:** Compiling first, then executing, so it never executes until their is no errors
	- **Example:** Translating a book from Arabic to English, but this time we translate the whole book first then read it 

- **Dynamic Typing:** JavaScript variable can change to different data types which leads to errors 
- **Static Typing:** TypeScript variable has a defined datatype at first 

- **TypeScript:** Transpiled, meaning it is converted to JavaScript first
- **JavaScript:** Interpret
